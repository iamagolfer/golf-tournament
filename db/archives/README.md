# db/archives — 封存快照的離線備份

線上封存（`archives` 資料表）只存在 Railway 的 volume 裡，**那是唯一一份**。
這個資料夾把它複製一份進 git，等於第二份保險：volume 掛掉、專案搬家、
Hobby 方案沒有自動備份的時候，這裡還原得回去。

## 檔案

| 檔案 | 內容 |
|---|---|
| `greenjacket-<year>.json` | 綠夾克某一年的完整快照（`GET /api/archives/<year>?t=greenjacket` 的原樣） |
| `ring-<year>.json` | 戒指盃某一年的完整快照 |
| `2026-09-04-live-backup.json` | 2026 綠夾克比賽隔天，從線上整包撈下來的原始資料（兩個賽事的當期狀態） |

每份快照包含：球場與 par、選手與差點、分組、每一洞的桿數，以及**當時算好的排名**
（綠夾克是淨桿／總桿；戒指盃另有最終排名與選馬結果）。PIN 一律不含 —— 拉取
腳本會檢查，發現就中止。

## 每年比賽後要做的事

```
1. 後台把狀態切成「已結束」/「選馬已公布」
2. 後台 → 歷屆冠軍 → 🔒 封存本次完整成績
3. 把新的一年抓下來放進這個資料夾,commit
```

第 3 步就是逐年把線上的封存拉一份下來存檔，抓的方式是打這兩個公開 API：

```
GET /api/archives?t=<slug>          ← 有哪些年份
GET /api/archives/<year>?t=<slug>   ← 那一年的完整快照
```

## 還原

這些是純資料，不是資料庫檔。要還原的話，把 JSON 的內容寫回 `archives` 資料表
對應的 `slug` / `year` / `data` 欄位即可（`data` 就是整份 JSON 的字串）。
